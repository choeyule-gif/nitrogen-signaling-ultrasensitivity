# Final plotting palette

The matplotlib hook applies the saturated Figure 1 palette during export, preserving plotted numerical arrays. Import `journal_style` before running a plotting module. Colors: blue #0690F6, orange #FF7B02, green #2BD302, red #FF1F1F, dark blue #0E56FF. Matplotlib/Helvetica rendering can differ slightly across platforms. MATLAB plot sources are under extras/revision_audited/code/matlab.
