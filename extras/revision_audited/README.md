# Foundational figure calculations

The `code`, `data`, and `figdata` directories retain the audited computations and MATLAB panel sources for the foundational response constraints. `code/rebuild_figures.py` regenerates numerical exports; the MATLAB scripts and `code/promote_supporting_panels.py` create the panel graphics. `code/assemble_figures.py` combines the supplied panels. Final manuscript numbering maps architecture, sensitivity and titration to Figures 2, 3 and 4. Numerical scope and assumptions are documented in the manuscript and supporting appendix.
