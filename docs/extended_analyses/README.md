# Extended analysis archive

Current submission supplements contain the core proofs (S1 Appendix, A1–A15), data and sensitivity analyses (S2 Appendix, D1–D7), and six supporting figures. `migration_map.json` maps source section identifiers and figure numbers into that organization.

`v1.2.0/` preserves unchanged copies of the previous two appendices, all seventeen previous supporting figures, and their figure inputs. These copies retain legacy identifiers and predate the generalized calibration extension. They are repository documentation, not additional submission supplements. The older extended manuscript duplicates material now in the main paper and is retained for provenance only.

The core migration retains source sections S1–S4, S18, S20–S22, S24–S29 plus the new calibration proof. The data migration retains S5, S7, S15, S17, S19 and S23 plus the independent peptide observation analysis. Other source sections remain accessible in the unchanged archive. No earlier analysis has been erased to reduce the submission burden.
