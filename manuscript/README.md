# Working submission manuscript

The PLOS LaTeX main manuscript contains text and captions with five separately supplied main figures. There are 33 references, S1 Appendix (S1–S29), S2 Appendix (extended analyses), and S1–S17 supporting figures. Compile each source twice with pdfLaTeX. All supporting figure inputs are in `figure_inputs/`.

Code v1.1.0 is archived at https://doi.org/10.5281/zenodo.22735182. The compressed manuscript and paired-paralog extension are released as GitHub v1.2.0; its Zenodo DOI is pending verification. The previous release ZIP is not the updated submission package.
